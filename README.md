# 图库plus

关键词图库插件：每个关键词配一个图片文件夹，群里发这个词，机器人就随机回一张图。

> 改造自 [astrbot_plugin_image_replay](https://github.com/cumany/astrbot_plugin_image_replay)（作者 cuman），感谢原插件。

## 能做什么

- **关键词回图**：消息首词命中关键词即随机发一张，一个关键词一个图库，互不干扰，增删图片不用改配置
- **聊天端指令**：`收集` 把引用的图片收进图库，`查看图片` 随机看一张，`删除图片指令` 删图或删库（管理员）
- **图库菜单**：发「图片帮助」回一张菜单图，把所有图库按「单人 / 合照 / 功能」分区、按角色名拼音首字母分列（准确拼音，生僻字也认），每条是「角色名称-关键词」，照着发就能出图；顶部背景图、菜单文字与各部件的中/英/日字体和字号都能在管理页「菜单预览」里所见即所得地改，每个图库还能单独设置是否进菜单、角色名称与分组
- **仪表盘管理页**：在 AstrBot WebUI 里建关键词、上传图片、看缩略图、悬停改 PID/删单张或整个图库，不用碰服务器文件
- **上传弹窗**：点上传按钮弹出上传弹窗，一次多选、多张并行上传，进度逐张显示，失败的图片置顶一键重传；关了弹窗上传也不停，页面右上角小窗继续显示动态
- **批量导入**：按自己的文件名格式一次导入大量图片，自动分到对应图库，不符合格式的会逐条说明原因；结果按图库汇总，失败/跳过的置顶方便重试
- **大图库不卡**：主页每行两张卡片、随机封面，滚动到底自动加载更多，几百个图库也能秒开
- **PID 记录与水印**（可选）：上传 pixiv 下载的图片（文件名里带作品号即可）自动记录作品号，发送时在图片下方附信息条——图片主色色块、文件名/PID、作品页二维码，不改原图；水印可按图库单独开关（默认开）
- **水印字体可换**：信息条的中文、西文/数字字体可在管理页分别设置（默认黑体）
- **输出格式可选**：`jpg`（默认，体积更小）或 `png`（无损），GIF 始终原样发送

## 安装

1. 把插件放进 AstrBot 的 `data/plugins/`（或从插件市场安装）
2. 重启 AstrBot
3. 依赖：Pillow
4. 仪表盘管理页需要较新版 AstrBot（支持插件 Pages）；版本过旧时管理页不可用，但关键词回图照常工作

## 使用

### 群里发关键词

```
可琳照片          # 随机回一张
可琳照片 来一张    # 取第一个词匹配，等效
```

发关键词取图**不需要**任何前缀或 @。

### 聊天端指令（需命令前缀）

指令走 AstrBot 命令系统，需带命令前缀（以 AstrBot 的唤醒前缀设置为准，默认 `/`）：

| 指令 | 别名 | 权限 | 说明 |
| --- | --- | --- | --- |
| `/收集 <图库名>` | `/添加图片`、`/添加表情` | 所有人 | 引用一条含图片的消息，把图收进该图库；不填图库名收进「临时」 |
| `/查看图片` | — | 所有人 | 从所有图库随机发一张 |
| `/删除图片指令 <图库名> [ALL]` | `/删除图片` | 管理员 | 默认删该库最近添加的一张；带 `ALL` 删整个图库 |
| `/图片帮助` | — | 所有人 | 回一张汇总所有图库的菜单图（直接发「图片帮助」也行，不需要前缀） |

### 图库菜单（图片帮助）

```
/图片帮助        # 带命令前缀
图片帮助          # 或直接发，两种都行
```

回的是一张菜单图：所有图库按「单人 / 合照 / 功能」分区，单人、合照两区再按角色名拼音首字母分列（A、B、C…），每条显示为 `角色名称-关键词`——照着发关键词就能拿到图。页眉显示图库更新日期与图片总数，页脚显示生成时间。

管理页右上角「菜单预览」里可以改，改动即时保存，右侧预览就是群里会收到的样子：

- **菜单文字**：标题、副标题、右上角标签、底部说明、右下角备注
- **各部件字体与字号**：标题 / 副标题 / 右上信息 / 分区标题 / 首字母 / 图库条目 / 底部信息，每个部件都能分别为 中文字体（汉字）、英文·数字、日文（假名）各选一个字体——选择框里**直接输入字体名字就能快速筛选**（像 Office 那样，显示的是字体自己的名字而不是文件名），也可以在本页上传自己的 `.ttf` / `.ttc` / `.otf`（上限 30MB，字体池与「水印设置」共用）；每个部件还能按百分比调字号（100 = 参考样式的大小，50~200）。页脚说明区为纯白底，与正文区分
- **顶部背景图**：上传自己的一张图铺在页眉（按比例裁满）。标题是白字，**请用深色图**；不传就用内置的深色渐变

每个图库的菜单选项在图库页「菜单设置」里：

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 在菜单里显示 | 显示 | 不想露出来的图库（比如临时库）可以关掉 |
| 角色名称 | 图库名 | 菜单里显示成 `角色名称-关键词` |
| 所属分组 | 个人 | `个人`（单人区）/ `团体`（合照区）/ `功能`（功能区的单列列表，不按字母分列） |

> 字母分组按角色名拼音首字母：依赖 `pypinyin`（安装插件时自动装上），生僻字（如「芙」）也能归对字母；个别极端缺字会落到「#」栏。

### 仪表盘管理页

AstrBot WebUI → 插件页 → 图库plus → 打开管理页：

- 创建 / 删除关键词（一个关键词就是一个图库）；新建的图库会排在第一张，刷新页面后恢复按图库名拼音排序
- 上传图片（可一次多选，支持直接用 pixiv 原始文件名，如 `95026140_p0.jpg`、`95026140_p0_master1200.jpg`、`作者名_95026140_p0.jpg`）；上传在弹窗里进行，多张并行，失败的可一键重传
- 主页每行两张卡片，封面从该图库随机取一张；点卡片进入图库，返回时**原样回到离开时的位置**（列表、翻页进度都不动）
- 主页卡片上的「图库设置」：不用进图库就能配置该库的菜单选项（是否进菜单 / 角色名称 / 所属分组）
- 图库内悬停缩略图：右下角「PID」弹窗改作品号，右上角「✕」删除该图
- 图库内勾选/取消「水印」单独控制该库发送时是否附加信息条（默认开）
- 图库内「菜单设置」配置该图库的菜单选项（是否进菜单 / 角色名称 / 所属分组）
- 右上角「菜单预览」：所见即所得地改菜单文字、各部件的中/英/日字体与字号、顶部背景图
- 批量导入

图库列表滚动到底自动加载更多，也可点「加载更多」。

### 批量导入

管理页右上角「批量导入」→ 用积木按钮拼出你的文件名格式 → 选图片 → 一键导入。

| 积木 | 含义 |
| --- | --- |
| `{图库名}` | 归到哪个图库（**必填**） |
| `{编号}` | 数字序号，仅用于匹配文件名（入库时按图库重新编号） |
| `{pid}` | pixiv 作品号（`95026140` / `95026140_p0`），会被记录 |
| `{扩展名}` | 文件后缀（也可写 `{格式}`） |

示例：

```
格式：{图库名}-{编号}.{扩展名}
文件：可琳照片-1.jpg、可琳照片-2.jpg、安比照片-1.png
结果：可琳照片 2 张、安比照片 1 张（编号自动接续该图库已有编号）

格式：{图库名}_{pid}.{扩展名}
文件：可琳照片_95026140_p0.jpg
结果：可琳照片新增 1 张，并记录 PID:95026140_p0
```

不符合格式的文件**不会被猜测**，会在结果里逐条列出跳过原因（格式不符 / 不支持的图片格式 / 内容解码失败等）。

导入过程中会实时显示进度与速度；结果默认折叠为按图库汇总（新增了哪些图库、各新增多少张），失败/跳过的图片置顶列出名单并可一键重试。

## 图片命名与 PID

- 文件名里有作品号就自动记录为 PID：纯数字（`95026140.jpg`）、`数字_p数字`（`95026140_p0.jpg`，带 `_master1200` 或作者/标题等前后缀也认）、`illust_` / `pixiv_` 前缀（`illust_95026140_20230101.jpg`）；认不出的不猜，显示「无PID」
- 入库后统一改名为 `关键词-编号.扩展名`，编号接续该图库已有最大编号（该库已有 30 张，新图就是 `关键词-31.jpg`）
- 记错了可以在管理页图库里**悬停缩略图**，点右下角「PID」弹窗修改（留空即清除）
- 开启水印时，发送的信息条会显示文件名与 PID

## 水印

开启后，发送的图片下方会临时拼接一条米白色信息条（原图与图库文件不被修改）：

- 左侧一个按**图片主色**自动变色的色块
- 中间两行文字：文件名，以及 PID（没有 PID 时显示「暂无 PID信息」）
- 右下角附**作品页二维码**（`https://www.pixiv.net/artworks/<PID>`，扫码直达），没有 PID 则不出码
- 信息条高度约为图片高度的 8%，**随图片尺寸等比缩放**，大图小图视觉比例一致
- GIF 动图直接原样发送，不加水印；不想要水印：把 `watermark` 关掉
- **按图库单独开关**：在图库里取消勾选「水印」，该图库发送的图片就都不带信息条（其他图库不受影响），默认开启

### 水印字体

管理页右上角「水印设置」里，信息条的**中文字体**与**西文/数字字体**可以分别选择（默认黑体）：

- **选系统字体**：下拉列表就是本机已安装的字体文件
- **上传字体文件**：点「上传字体文件」把 `.ttf` / `.ttc` / `.otf` 传进插件字体池（上限 30MB），上传后即可在下拉里选到——例如 **OPPO Sans**（中文，[官方下载](https://open.oppomobile.com/new/developmentDoc/info?id=13223)，免费商用）与 **Reo Sans Light**（西文/数字，商业字体，请自行购买授权）

## 输出格式

- `output_format` 选 `jpg`（默认，体积更小）或 `png`（无损）
- 只影响信息条的临时文件，GIF 始终原样发送

## 配置项

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `require_wake` | `false` | 开启后需 @机器人/唤醒前缀 才响应关键词，避免误触发 |
| `watermark` | `true` | 发送时附加信息条（主色块 + 文件名/PID + 作品二维码）；关掉则全部图库都不加，开时可在管理页按图库单独关 |
| `output_format` | `jpg` | 发送图片格式：`jpg` 体积更小，`png` 无损；GIF 始终原样发送 |
