# 图库plus

关键词图库插件：每个关键词配一个图片文件夹，群里发这个词，机器人就随机回一张图。

> 改造自 [astrbot_plugin_image_replay](https://github.com/cumany/astrbot_plugin_image_replay)（作者 cuman），感谢原插件。

## 能做什么

- **关键词回图**：消息首词命中关键词即随机发一张，一个关键词一个图库，互不干扰，增删图片不用改配置
- **仪表盘管理页**：在 AstrBot WebUI 里建关键词、上传图片、看缩略图、删单张或整个图库，不用碰服务器文件
- **批量导入**：按自己的文件名格式一次导入大量图片，自动分到对应图库，不符合格式的会逐条说明原因
- **大图库不卡**：图库默认折叠只显示名称与张数，滚动到底自动加载更多，几百个图库也能秒开
- **PID 记录与水印**（可选）：上传 pixiv 命名的图片自动记录作品号，发送时在图片下方附一条 文件名/PID 信息条，不改原图
- **输出格式可选**：`jpg`（默认，体积更小）或 `png`（无损），GIF 始终原样发送

## 安装

1. 把插件放进 AstrBot 的 `data/plugins/`（或从插件市场安装）
2. 重启 AstrBot
3. 依赖：Pillow
4. 仪表盘管理页需要较新版 AstrBot（支持插件 Pages）；版本过旧时管理页不可用，但关键词回图照常工作

## 使用

### 群里发关键词

```
可琳照片          # 随机回一张
可琳照片 来一张    # 取第一个词匹配，等效
```

### 仪表盘管理页

AstrBot WebUI → 插件页 → 图库plus → 打开管理页：

- 创建 / 删除关键词（一个关键词就是一个图库）
- 上传图片（可多选，支持直接用 pixiv 原始文件名，如 `95026140_p0.jpg`）
- 浏览缩略图、删除单张图片或整个图库
- 批量导入

图库列表默认折叠，只显示名称与张数；点开某个图库才加载图片，滚动到底自动加载更多，也可点「加载更多」。

### 批量导入

管理页右上角「批量导入」→ 用积木按钮拼出你的文件名格式 → 选图片 → 一键导入。

| 积木 | 含义 |
| --- | --- |
| `{图库名}` | 归到哪个图库（**必填**） |
| `{编号}` | 数字序号，仅用于匹配文件名（入库时按图库重新编号） |
| `{pid}` | pixiv 作品号（`95026140` / `95026140_p0`），会被记录 |
| `{扩展名}` | 文件后缀（也可写 `{格式}`） |

示例：

```
格式：{图库名}-{编号}.{扩展名}
文件：可琳照片-1.jpg、可琳照片-2.jpg、安比照片-1.png
结果：可琳照片 2 张、安比照片 1 张（编号自动接续该图库已有编号）

格式：{图库名}_{pid}.{扩展名}
文件：可琳照片_95026140_p0.jpg
结果：可琳照片新增 1 张，并记录 PID:95026140_p0
```

不符合格式的文件**不会被猜测**，会在结果里逐条列出跳过原因（格式不符 / 不支持的图片格式 / 内容解码失败等）。

导入过程中会实时显示成果：按图库分组列出新入库的图片与张数、导入速度与预计剩余时间；结束后可展开跳过名单，并一键重试跳过的文件。

## 图片命名与 PID

- 原始文件名是纯数字（如 `95026140.jpg`）或 `数字_p数字`（如 `95026140_p0.jpg`）→ 自动记录为 PID
- 入库后统一改名为 `关键词-编号.扩展名`，编号接续该图库已有最大编号
- 开启水印时，发送的信息条会显示文件名与 PID

## 水印与输出格式

- 水印**只在发送时**临时拼接（图片下方一条深色信息条，内容为文件名与 PID），原图与图库文件不被修改
- GIF 动图直接原样发送，避免只剩第一帧
- 不想要水印：把 `watermark` 关掉
- 输出格式：`output_format` 选 `jpg`（默认，体积更小）或 `png`（无损）

## 配置项

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `require_wake` | `false` | 开启后需 @机器人/唤醒前缀 才响应关键词，避免误触发 |
| `watermark` | `true` | 发送时附加 文件名/PID 信息条 |
| `output_format` | `jpg` | 发送图片格式：`jpg` 体积更小，`png` 无损；GIF 始终原样发送 |
